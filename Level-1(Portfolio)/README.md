# 💼 Personal Portfolio

A simple and professional personal portfolio website built using **HTML and CSS**. Developed as part of the **CodeVeda Full-Stack Development Internship**.

## 📌 Project Overview

The Personal Portfolio website presents personal information and provides an overview of the projects and profile through a clean and simple design.

## ✨ Features

* Home section
* About section
* Projects section
* Contact section
* Simple navigation
* Clean and professional design
* Responsive layout

## 🛠️ Technology Stack

| Layer     | Technology |
| --------- | ---------- |
| Structure | HTML5      |
| Styling   | CSS3       |

## 🚀 How to Run

1. Download or clone the repository.
2. Open the **Portfolio** project folder.
3. Open `index.html` in any web browser.

## 🎯 Purpose

This project was developed to practice **HTML and CSS** and create a simple and professional personal portfolio website.
