# 🛍️ MyShop

A simple and professional static shopping website built using **HTML and CSS**. Developed as part of the **CodeVeda Full-Stack Development Internship**.

## 📌 Project Overview

MyShop is a simple shopping website designed with a clean and user-friendly interface. It includes multiple pages with easy navigation and a responsive layout.

## ✨ Features

* Clean and professional design
* Home page
* About page
* Contact page
* Easy navigation
* Responsive layout
* User-friendly interface

## 🛠️ Technology Stack

| Layer     | Technology |
| --------- | ---------- |
| Structure | HTML5      |
| Styling   | CSS3       |

## 📂 Project Structure

```text
MyShop/
│
├── index.html
├── about.html
├── contact.html
└── style.css
```

## 🚀 How to Run

1. Download or clone the repository.
2. Open the **MyShop** project folder.
3. Open `index.html` in any web browser.
4. Use the navigation links to explore the website.

## 🎯 Purpose

This project was developed to practice **HTML and CSS** and gain practical experience in creating a simple and professional static shopping website.
