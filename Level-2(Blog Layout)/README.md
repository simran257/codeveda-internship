# 📝 Blog Layout Website

A simple and responsive blog layout website built using **HTML and CSS**. Developed as part of the **CodeVeda Full-Stack Development Internship**.

## 📌 Project Overview

The Blog Layout Website provides a clean and structured interface for displaying blog posts and articles. It focuses on a professional layout, easy navigation, and responsive design.

## ✨ Features

* Clean and professional design
* Responsive layout
* Navigation bar
* Blog posts and articles
* Featured posts section
* Categories section
* User-friendly interface
* Structured content layout

## 🛠️ Technology Stack

| Layer    | Technology |
| -------- | ---------- |
| Frontend | HTML5      |
| Styling  | CSS3       |

```text
Blog-Layout/

```

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

## 🎯 Purpose

This project was developed to practice **HTML and CSS**, create a responsive web layout, and gain practical experience in front-end web development.
