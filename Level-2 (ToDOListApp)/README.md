# 📝 To-Do List App

A simple and user-friendly To-Do List application built using **HTML, CSS, and JavaScript**. Developed as part of the **CodeVeda Full-Stack Development Internship**.

## 📌 Project Overview

The To-Do List App helps users organize and manage their daily tasks efficiently. Users can add, complete, and delete tasks through a simple and intuitive interface.

## ✨ Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* View pending and completed tasks
* Simple and clean user interface
* Responsive design
* Easy task management

## 🛠️ Technology Stack

| Layer         | Technology |
| ------------- | ---------- |
| Structure     | HTML5      |
| Styling       | CSS3       |
| Functionality | JavaScript |

## 📂 Project Structure

```text
To-Do-List/
│
├── index.html

└── script.js
```

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Start adding and managing your tasks.

## 🎯 Purpose

This project was developed to practice **HTML, CSS, and JavaScript**, while gaining practical experience in building an interactive task management application.
